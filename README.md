# Águila Blanca — Sitio Web Oficial & Landing Comercial PDR

Sitio web oficial y landing page de alta conversión para **Águila Blanca**, centro técnico especializado en la reparación artesanal de abolladuras por granizo y toques de estacionamiento mediante técnica **PDR (Paintless Dent Repair)** sin dañar la pintura original.

## 🚀 Características Principales

- **Hero de Alto Impacto:** Propuesta de valor clara, indicadores de confianza y llamado a la acción directo.
- **Cotizador Rápido de Daño:** Selector interactivo en 3 pasos (Tipo de vehículo, Zonas afectadas, Tipo de daño y Seguro) que genera un mensaje listo para enviar al perito por WhatsApp.
- **Slider Interactivo Antes / Después:** Comparación interactiva deslizable con simulación de reflexión lumínica PDR y ficha técnica de casos reales.
- **Comparativa PDR vs Taller Tradicional:** Tabla detallada de beneficios (conservación de pintura OEM, valor de reventa, tiempos de 24-48 hs, garantía total).
- **Gestión Integral con Seguros:** Homologación y presupuestos oficiales para las principales aseguradoras (La Segunda, San Cristóbal, Federación Patronal, Zurich, Rivadavia, Sancor, Allianz, etc.).
- **Proceso en 4 Pasos:** Escaneo óptico LED, presupuesto pericial, masaje artesanal milimétrico y control reflectométrico 360°.
- **División Flotas & Concesionarias:** Atención B2B para tormentas masivas y lotes de 0km.
- **Preguntas Frecuentes (FAQ):** Resolución de objeciones técnicas para clientes de vehículos nuevos y de alta gama.
- **Enlace al Sistema de Gestión:** Acceso directo al sistema del taller para clientes y personal.
